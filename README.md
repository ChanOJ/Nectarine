# Nectarine

**Nectarine, the demoscene radio (www.scenemusic.net, nectarine.ojuice.net, 2000 to 2006).**
A web radio playing more than 18,000 demoscene songs (modules, chiptunes, SID, MP3) requested
and rated by its listeners: song pages with votes, comments and party rankings, authors, charts,
news, oneliner and requests. It ran on the in-house engine id3 (classic ASP) over SQL Server,
next to Orange Juice, whose accounts it shared.

Published as a **100 % static, read-only archive** on bunny.net at the hostname of
[`site.json`](site.json) (`nectarine.sauthier.family`), like
[OrangeJuiceV3](https://github.com/ChanOJ/OrangeJuiceV3). The engine is not ported nor
published: a Python renderer pre-renders the `$$MACRO$$` templates of the skin over a SQLite
extraction of the databases. The radio streams are gone: the archive shows the station as it
was when it stopped (2006-09-07), off the air.

## Layout

| Path | Content |
| --- | --- |
| `site/` | The generated static site (never edit by hand; **git-ignored**): skin `n`, `/js/nec.js`, search indexes in `/idx/`, `robots.txt`, `sitemap.xml` |
| `hosting/404.html` | Custom 404 page (generated with `site/`) |
| `build-meta/` | `url-map.json` (old query URL -> static file, checked by the Edge Script test), `unlinked.tsv` |
| `site.json` | Hosting settings: owner, repository, storage zone, pull zone, hostname, 404 page |
| `docs/data-model.md` | Engine, tables and columns used, URL scheme, removed features, redactions |
| `scripts/statify.py` | Raw store -> `site/` + `hosting/404.html` + `build-meta/` (crawl of the rendered pages) |
| `scripts/id3render/engine.py`, `scripts/id3render/nec.py` | The id3 template engine and the Nectarine data macros, reimplemented |
| `scripts/nec.js` | Source of `site/js/nec.js`: colour themes, client-side search |
| `scripts/seo.py` | `robots.txt` (allow all) and `sitemap.xml` |
| `scripts/verify_build.py`, `scripts/check_excludes.py` | Checks of `site/` |
| `scripts/mdf/` | Pure-Python reader of SQL Server 2000 `.MDF` files and the MDF to SQLite extractor |
| `infra/`, `scripts/deploy.py`, `scripts/publish.sh`, `scripts/smoke_test.py`, `scripts/bootstrap.sh` | Hosting, as OrangeJuiceV3 |
| `private/` | Notes and Wayback captures, **git-ignored** |

Inputs are read from the shared raw store of the id3/id3x sites, `~/Code/id3x/raw` (one setting:
`RAW` in `scripts/statify.py`, or the `ID3X_RAW` environment variable): skin `id3/z/n/`, media
`id3/zi/`, databases `db/NECTARINE.sqlite` and `db/OJUICE.sqlite`. It holds personal data and
credentials and is never published; only rendered pages and the files they reference are copied.

## What the archive keeps and drops

- Kept: home page (frozen on the last song played), every song page (18,508) with its votes,
  comments and party rankings, authors by letter and their songs, author information, song and
  user charts, news and their comments, the oneliner day by day, FAQ, listen, credits, links.
- The 15 colour themes of the site (chosen per account on the live site) are offered on
  `/themes.htm` and kept in the browser (localStorage, no cookie).
- Removed: logins, requests, votes, comments, uploads, favourites, DJ sessions, private messages,
  admin pages, the guestbook, the member list, the list of donors, listener statistics (frozen
  at 0), the stream relays (the station is shown off the air), ads and analytics, pouet.net
  screenshots (third-party images), the forums (Web Wiz Forums, not archived).
- Every page ends with "To be removed from this page, contact me." (pages show nicknames).

## Regenerating `site/`

`site/` is generated: never edit it by hand, fix the scripts and regenerate (a few minutes):

```bash
python3 -I scripts/statify.py
```

```bash
python3 -I scripts/verify_build.py
```

```bash
python3 -I scripts/check_excludes.py
```

Local preview (the `site` entry of `.claude/launch.json`):

```bash
python3 -m http.server 3561 --directory site
```

## Hosting and deploying

Same as OrangeJuiceV3 (see its README): bunny.net storage and pull zone managed by OpenTofu
(`infra/`), read-only edge rules and security headers, a middleware Edge Script
(`infra/edge/redirects.js`, generated by `scripts/gen_edge_script.py`, tested by
`scripts/test_edge_script.mjs`) that answers the old query URLs (`/info.htm?idsong=51362` ->
`/info-song51362.htm`, `/research.htm?author=4+Mat` -> `/research-author4-mat-7db735.htm`). The
site is deployed from the Mac with `scripts/publish.sh` (Proton Pass CLI logged in):

```bash
scripts/publish.sh
```
